# minitools

ちょっと便利な小さな道具箱。日常のちょっとした用事から、エンジニアの手元の作業まで。
すべてブラウザ内で動作し、入力内容をサーバーへ送信しません。

## 公開中のツール

**誰でも使えるツール**
- **パスワード生成器** (`/tools/password/`) — 暗号学的に安全な乱数で作るランダムパスワード。強度の目安つき。
- **文字数・バイト数カウンター** (`/tools/charcount/`) — X（旧Twitter）やThreadsなどの文字数上限プリセットつき。
- **単位変換ツール** (`/tools/units/`) — 長さ・重さ・温度の変換。メートル法⇄ヤード・ポンド法。
- **QRコード作成** (`/tools/qr/`) — URLや文章からQRコードを生成し、PNG画像かSVGで保存。
  誤り訂正レベルと大きさを選べる。
- **関数電卓** (`/tools/calc/`) — 三角関数・対数・平方根・べき乗・階乗に対応した電卓。
  式をまとめて書けて、度とラジアンを切り替えられる。

**エンジニア向け**
- **cron式チェッカー** (`/tools/cron/`) — cron式を日本語の説明文に変換し、次の実行時刻を一覧表示する。
  日と曜日を両方指定したときのOR条件（標準cronの仕様）も正しく計算する。
- **Unixタイムスタンプ変換** (`/tools/timestamp/`) — タイムスタンプ⇄日時の相互変換。秒とミリ秒の自動判定つき。
- **JSON整形・検証ツール** (`/tools/json/`) — JSONを整形・ミニファイし、構文エラーを行番号つきで表示。重複キーも検出。

## ツール以外のページ

- **プライバシーポリシー** (`/privacy/`) — Google AdSense の必須コンテンツ要件
  （第三者配信事業者のCookie利用 / パーソナライズ広告の無効化導線 / 第三者広告ネットワークの開示）に対応。
  **広告はまだ掲載していないため、広告に関する記述はすべて「掲載する場合」の将来形**で書いてある。
  実際に広告タグを貼ったら現在形に直し、`PRIVACY_POLICY_UPDATED`（`src/consts.ts`）も更新する。
- **お問い合わせ** (`/contact/`) — 連絡先は `src/consts.ts` の `CONTACT_EMAIL`。
  **現在はプレースホルダ（`CONTACT_EMAIL_TODO`）で、本番公開前に実在のアドレスへ差し替えが必要。**
  プレースホルダのままの間は mailto リンクを出さず「準備中」と表示する。

## 技術構成

| 役割 | 使用しているもの |
|---|---|
| 静的サイトジェネレータ | [Astro](https://astro.build/) |
| ホスティング | Cloudflare Workers（静的アセット配信） |
| ソース管理 / CI | GitHub |

Cloudflare を選んだ理由は、GitHub Pages の利用規約が商用目的のサイトを
明示的な許可対象に含めておらず、Cloudflare は商用利用を明示的に許容しているため。
帯域制限も緩い。デプロイ設定は `wrangler.jsonc` を参照。

## 開発

Node.js 22.12 以上が必要（`.zshrc` の fnm 経由で管理）。

```sh
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト
npm run check    # 型チェック + テスト
npm run build    # dist/ に静的出力
```

ツールの追加手順と実装上の注意は [AGENTS.md](./AGENTS.md) を参照。

## 設計方針

- ツールのロジックは `src/lib/` に純粋な関数として置き、テストを書く。UIには依存させない。
- 処理はクライアントサイドで完結させる。入力内容を外部に出さないことがこのサイトの前提。
- 中途半端にサポートするより、対応しない仕様は明確にエラーにして理由を説明する。
