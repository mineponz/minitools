# minitools

エンジニア向けのミニツール集。すべてブラウザ内で動作し、入力内容をサーバーへ送信しません。

## 公開中のツール

- **cron式チェッカー** (`/tools/cron/`) — cron式を日本語の説明文に変換し、次の実行時刻を一覧表示する。
  日と曜日を両方指定したときのOR条件（標準cronの仕様）も正しく計算する。

## 技術構成

| 役割 | 使用しているもの |
|---|---|
| 静的サイトジェネレータ | [Astro](https://astro.build/) |
| ホスティング | Cloudflare Pages |
| ソース管理 / CI | GitHub |

Cloudflare Pages を選んだ理由は、GitHub Pages の利用規約が商用目的のサイトを
明示的な許可対象に含めておらず、Cloudflare Pages は商用利用を明示的に許容しているため。
帯域制限も緩い。

## 開発

Node.js 22.12 以上が必要（`.zshrc` の fnm 経由で管理）。

```sh
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト
npm run check    # 型チェック + テスト
npm run build    # dist/ に静的出力
```

ツールの追加手順と実装上の注意は [AGENTS.md](./AGENTS.md) を参照。

## 設計方針

- ツールのロジックは `src/lib/` に純粋な関数として置き、テストを書く。UIには依存させない。
- 処理はクライアントサイドで完結させる。入力内容を外部に出さないことがこのサイトの前提。
- 中途半端にサポートするより、対応しない仕様は明確にエラーにして理由を説明する。
